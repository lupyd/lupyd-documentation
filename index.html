Quick Start

Get up and running with Lupyd in just a few steps.

1

Installation

Install Lupyd using your preferred package manager

npm install lupyd
2

Initialize

Set up your Lupyd configuration

lupyd init --project myapp
3

Deploy

Deploy your application with a single command

lupyd deploy

API Reference

Complete reference for all Lupyd API endpoints.

GET /api/projects

Retrieve all projects

Response:
{ "projects": [...] }
POST /api/projects

Create a new project

Response:
{ "id": "proj_123", "status": "created" }
PUT /api/projects/:id

Update an existing project

Response:
{ "id": "proj_123", "status": "updated" }
DELETE /api/projects/:id

Delete a project

Response:
{ "status": "deleted" }

Authentication

Secure your API requests with authentication tokens.

API Key Authentication

Include your API key in the Authorization header of your requests.

// Example request
curl -H "Authorization: Bearer YOUR_API_KEY" \
    https://api.lupyd.com/v1/projects

Code Examples

Practical examples to help you integrate Lupyd into your applications.

Basic Project Creation

Create a new project using the Lupyd API

import { LupydClient } from 'lupyd'

const client = new LupydClient({
  apiKey: process.env.LUPYD_API_KEY
})

const project = await client.projects.create({
  name: "My New Project",
  description: "A sample project"
})

React Integration

Using Lupyd with React applications

import { useLupyd } from 'lupyd/react'

function MyComponent() {
  const { projects, loading } = useLupyd()

  if (loading) return <div>Loading...</div>

  return (
    <div>
      { projects.map(project => (
        <div key={project.id}>{project.name}</div>
      )) }
    </div>
  )
}
